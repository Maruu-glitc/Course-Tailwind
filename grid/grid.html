Grid with Colspan

Column Span (col-span-n) Digunakan untuk menentukan berapa banyak kolom yang akan ditempati oleh satu item. Aturan: Nilai n tidak boleh melebihi jumlah total kolom pada parent. Jika parent punya grid-cols-3, maka maksimal adalah col-span-3. Class Khusus: col-span-full digunakan agar item otomatis memenuhi satu baris penuh, berapapun jumlah kolomnya. Kegunaan: Membuat Header, Banner, atau Footer.

Grid With Row Span

Row Span (row-span-n) Digunakan untuk menentukan berapa banyak baris yang akan ditempati oleh satu item (memanjang ke bawah). Aturan: Agar terlihat hasilnya, item di sebelahnya harus cukup banyak atau parent harus memiliki tinggi yang ditentukan (h-screen atau h-96). Kegunaan: Membuat Sidebar yang tingginya melewati beberapa baris konten.

Grid With col-start/col-end

Column Start & End (col-start-n / col-end-n) Digunakan untuk memaksa item mulai di garis kolom tertentu. Konsep Garis: Jika ada 3 kolom, maka ada 4 garis vertikal. col-start-1: Mulai dari garis paling kiri.col-start-2: Mulai dari tengah (setelah kolom pertama).Aturan: Ini akan menggeser item lain. Jika kamu menaruh item di col-start-3, maka kolom 1 dan 2 akan kosong jika tidak ada item lain.
